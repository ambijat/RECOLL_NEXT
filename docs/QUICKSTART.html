Privacy check: use copies of non-sensitive practice files while learning. Semantic stores contain passages, paths, number vectors, questions, and saved answers. The .local folder is ignored by Git, but it is still sensitive data on your computer.
What does “indexed” mean?

An index is a lookup map, like the index at the back of a textbook. Recoll reads the selected files first and records searchable words and metadata. Recoll Next does not secretly crawl every folder.

3Make a safe Python workspace

A virtual environment is a project-sized toolbox. It keeps this project's Python setup separate from other Python projects.

Use the offline-safe project helper:

python src\semantic\initsemenv.py .venv --verify
.\.venv\Scripts\Activate.ps1
python --version

Or create it directly with the verified Python version:

py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
python --version

Run the automated project checks:

python -W error::ResourceWarning -m unittest discover -s tests\semantic

Success looks like: the final lines report a number of tests followed by OK. The exact count can grow as the project grows.

The environment helper does not download packages, Recoll, Ollama, or models. A copied .venv is not considered portable to another computer.

4Get a first win with Exact search

Exact search is the safety net. It uses Recoll's normal index and needs neither Ollama nor a semantic SQLite store.

python src\semantic\recoll_ai.py search --mode exact --limit 3 'filename:"GOAL_FIDELITY.md"'

If that file is not in your Recoll profile, substitute the real name of one small, non-sensitive text or Markdown file. Text written in capital placeholders is never meant to be entered literally.

Success looks like: up to three results appear in Recoll's order, with titles or source paths. If this fails, fix Recoll before adding the AI layers.

Why start here?

It proves that document discovery, the active Recoll profile, and the Python bridge work. It also demonstrates the project's promise that ordinary search survives when AI is unavailable.

5Check the local AI

Install Ollama and the two configured models through an adult-, operator-, or organization-approved method. Then inspect what is already available:

ollama --version
ollama list
python src\semantic\recoll_ai.py doctor

The defaults are the embedding model embeddinggemma, the chat model gemma3:4b, and the loopback endpoint http://127.0.0.1:11434. All three are configurable.

Success looks like: doctor reports ready, a loopback address, and no missing models. The check only inspects readiness; it does not install, start, or change Ollama.

Model downloads are an outside action. Commands such as ollama pull embeddinggemma and ollama pull gemma3:4b contact a model registry. Run them only with explicit permission and after reviewing model license, network, disk-space, and school or workplace rules.

6Build a small practice idea index

The semantic index stores passages and meaning vectors in a separate SQLite file. Start with a few known practice documents, not an entire drive.

  1. Double-click Rebuild-Index.bat, or run the command below.
  2. Choose .local\practice-small.sqlite3 as the store.
  3. Enter filename:"GOAL_FIDELITY.md", or the verified filename of one small document.
  4. Test that same query in ordinary Recoll first.
  5. Leave the safety checkbox checked and click Run Semantic Indexing.
python src\semantic\recoll_ai_index_builder.py --store .local\practice-small.sqlite3

The builder now exposes request timeout, batch size, and total limit. Its beginner defaults are 120 seconds, 4 segments, and 900 seconds. It reports document and batch progress and stops at the total limit. A large PDF is a later performance test, not a first-run test.

Keep documents missing from this scope (never delete) is checked by default. Leave it checked whenever your scope query only covers part of what the store holds — unchecking it deletes every document in the store that the current query didn't match. Only uncheck it when the query intentionally represents the store's entire intended scope.

An immediate second run over an unchanged scope should report zero newly embedded segments — that's the synchronizer confirming it is idempotent.

Idempotent means “running the same completed job again does not redo unchanged work.” New or changed documents are embedded; unchanged ones are skipped.

7Open the AI Perspective workspace

Double-click AI-Perspective.bat, or launch the Tk desktop companion:

python src\semantic\recoll_ai_gui.py --store .local\practice-small.sqlite3

The window separates two jobs: first find evidence, then choose whether to interpret it. AI operations run in a separate child process, so they can be cancelled without stopping ordinary Recoll search.

8Find and inspect evidence Step 1

  1. Type a question whose answer appears in the practice documents.
  2. Choose Prismatic for a blend of word and idea matches.
  3. Click Find evidence.
  4. Click each result and read its preview. Notice its source and “found via” label.
  5. Double-click a row when you want to inspect the original file.
Keep both channels in the same practice scope. A one-document semantic store combined with an unrestricted, drive-wide Recoll query can rank unrelated lexical results beside the semantic result. For this practice run, query filename:"GOAL_FIDELITY.md" original purpose.
ModeUse it when…
ExactYou know the words, phrase, filename, or Recoll filter. It needs no AI store.
PrismaticYou want both word matches and idea matches. If semantics fail, lexical evidence can still appear with a fallback notice.
ConceptualYou remember the idea but not the wording. Every hit must still match a current Recoll document revision.

Pause and check: do the visible passages really relate to the question? Retrieval can be imperfect. Select evidence because you read it, not merely because it ranked first.

9Interpret selected evidence Step 2

  1. Select one or two useful evidence rows. If none are selected, the top two are used.
  2. Choose answer, summary, timeline, contradictions, decisions, or actions.
  3. For the first practice run, leave Remember validated perspective locally unchecked.
  4. Click Interpret selected (or top 2).
  5. Wait or use Cancel. CPU generation may take several minutes.
  6. Read the result and open every cited source before relying on it.

Before generation, the app repeats the search and checks each selected rank and segment ID. After generation, it rejects unknown, missing, or unresolved citation IDs. This is called fail closed: an error is safer than an unsupported answer.

Citations do not make AI automatically correct. They show which supplied passages support the answer. You must still decide whether the wording is fair, complete, and appropriate for your assignment or decision.
Command-line version
python src\semantic\recoll_ai.py ask `
  --store .local\practice-small.sqlite3 `
  --mode conceptual `
  --view summary `
  --evidence-limit 2 `
  --timeout 300 `
  --no-remember `
  "What rules prevent this project from losing its original purpose?"

10Remember or forget a perspective

If you deliberately check Remember validated perspective locally, a successfully cited answer is saved as secondary memory. Search saved perspectives:

python src\semantic\recoll_ai.py memory-search --store .local\practice-small.sqlite3 --limit 5 "original purpose"

Only memories whose cited segment, document, and source revision still resolve are returned — a memory whose source has since changed is suppressed rather than shown stale.

Leave the checkbox off, or use --no-remember, for private or temporary questions. Remembered question and answer text stays local but is stored inside the SQLite file. The current GUI does not yet include a memory manager for viewing and deleting entries.

11Fix common problems

Ollama unavailable
Exact search keeps working. Start or repair Ollama, then re-run doctor.

Models missing
doctor tells you which configured tags are absent. Provision them only through an approved method.

Empty semantic results
Confirm the store path, the embedding model/namespace, the sync scope query, and the document count.

"Visible evidence changed; run Find Evidence again"
The underlying result set moved since you selected it — re-run Find Evidence and re-select before interpreting.

Recoll binding unavailable
Windows Python-ABI mismatches are bridged automatically; pass --recoll-python explicitly if auto-discovery fails.

GUI looks frozen
Generation can take minutes on CPU. Use Cancel — it only stops the AI child process, never ordinary Recoll search.

Ledger verification failure
Preserve the file untouched and diagnose the first bad line; never hand-edit governance/events.jsonl.

Typed errors are intentional. The program avoids dumping full internal tracebacks because those could reveal private passages or paths.
