The brochure

A private librarian, not an oracle

Recoll Next is an evidence-exploration system for documents already on your computer. It keeps fast deterministic search and adds optional conceptual retrieval and synthesis you can inspect.

LOCAL-FIRST

Your material stays local

Documents, extracted text, embeddings, prompts, and generated perspectives remain on the workstation by default. Ollama uses loopback.

EVIDENCE-FIRST

Every answer shows its work

Generated output must cite supplied segment identifiers. Invalid, missing, or invented citations make the synthesis fail closed.

RESILIENT

Search survives AI failure

Recoll and Xapian remain authoritative. Exact search works even when Ollama or the semantic sidecar is unavailable.

The operating model

Originals first. Interpretation last.

Each layer has one job and a clear source of truth. Derived AI data can be rebuilt without changing original documents or Recoll's lexical index.

Polaroid: factual evidence

A stable result card holds source identity, title, path, offsets, retrieval provenance, and indexed passage.

Prism: optional perspective

Summary, timeline, contradiction, decision, action, and answer views organize selected evidence without replacing it.

Three retrieval modes

Choose how literal or conceptual search should be

EXACT

Recoll order, unchanged

Uses the authoritative profile and Xapian rank. It needs neither a semantic store nor Ollama.

PRISMATIC · DEFAULT

Lexical + semantic

Runs bounded channels concurrently and combines ranks with reciprocal-rank fusion. Semantic failure visibly falls back to lexical evidence.

CONCEPTUAL

Ideas beyond exact words

Uses local embeddings, then accepts a hit only when identity and revision still resolve through live Recoll.

Operator manual

From checkout to first cited answer

This is the validated Windows/PowerShell path. Run it from the repository root. Installing Recoll, Ollama, or models is a separately authorized workstation step.

1

Know the four moving parts

You need the Recoll Next source, Python, an installed Recoll runtime/profile, and local Ollama. Default models are embeddinggemma and gemma3:4b.

Source is not data. Corpus files, profiles, Xapian indexes, semantic databases, and model files are separate local capsules.
2

Create the Python environment

The semantic slice uses the standard library and downloads no packages during bootstrap.

python src\semantic\initsemenv.py .venv --verify
.\.venv\Scripts\Activate.ps1
python --version

On POSIX, use source .venv/bin/activate. Recreate the environment on each machine.

3

Select and validate a Recoll profile

topdirs defines the corpus and dbdir defines Xapian. Confirm ordinary Recoll search before semantic synchronization.

python src\semantic\recoll_ai.py search `
  --mode exact --limit 5 "your literal query"
Never assume copied paths are valid. Remap every corpus root and database path deliberately.
4

Check local AI readiness

python src\semantic\recoll_ai.py doctor
python src\semantic\recoll_ai.py doctor --json

This confirms loopback policy and model inventory. It does not start Ollama or download models.

5

Build a scoped semantic sidecar

python src\semantic\recoll_ai.py sync `
  --store .local\practice.sqlite3 `
  --query "mime:text/markdown" `
  --timeout 120 --batch-size 4 `
  --max-runtime 900 --progress `
  --keep-missing
Deletion boundary: without --keep-missing, a successful sync removes sidecar documents absent from the current query. Use one store per scope, or keep the flag for partial scopes. Source files and Xapian are never deleted.
6

Search and inspect evidence

python src\semantic\recoll_ai.py search `
  --store .local\practice.sqlite3 `
  --limit 5 "the idea you are looking for"

python src\semantic\recoll_ai.py search `
  --mode conceptual `
  --store .local\practice.sqlite3 `
  --limit 5 "the idea you are looking for"

Inspect title, source, offsets, provenance, and rank before asking for interpretation.

7

Generate a cited perspective

python src\semantic\recoll_ai.py ask `
  --store .local\practice.sqlite3 `
  --view summary --evidence-limit 2 `
  --timeout 600 `
  "Summarize the evidence and cite it."

Views: answer, summary, timeline, contradictions, decisions, and actions. Add --no-remember for an ephemeral answer.

Routine operation

A small daily checklist

Start

  • Activate the recreated environment.
  • Run doctor.
  • Verify the governance ledger.
  • Identify working-tree changes.
  • Confirm the selected Recoll profile.

Before a long sync

  • Let Recoll indexing finish.
  • Validate the scope query in Recoll.
  • Use a separate or backed-up store.
  • Choose --keep-missing deliberately.
  • Set bounded timeouts.

Privacy, integrity, recovery

Boundaries operators never blur

Private by default

Do not commit corpus content, databases, runtime ledgers, prompts, answers, exports, credentials, profiles, or model blobs.

Derived means rebuildable

Preserve incompatible stores and rebuild into a new path. Never repair Xapian or a hash chain by editing internal files.

Remote means explicit

Git and model remote access are default-deny. Exact publication authority never expands to private data or unrelated refs.

Possible disclosure? Stop the process without deleting evidence, disconnect the path, preserve bounded logs and ledger heads, rotate credentials outside the repository, and follow the incident procedure.
Troubleshooting

Fail safely, then repair the derived layer

SymptomSafe response
Ollama unavailableKeep using Exact; repair Ollama and rerun doctor.
Model missingProvision the exact tag only with download/install authorization.
Recoll binding failsUse bundled-Python discovery or --recoll-python.
Empty semantic resultsConfirm store, namespace, model, scope, and synchronization.
Dimension mismatchSelect the correct namespace or rebuild; never coerce vectors.
Stale evidence rejectedResynchronize from the authoritative Recoll profile.
Generation is slowKeep evidence visible, wait, or cancel the owned child.
Ledger verification failsPreserve it and diagnose the first invalid event; never edit history.
