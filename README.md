# Recoll Next

A local-first knowledge system being rebuilt on the inherited Recoll indexing engine.
The repository is intentionally a development skeleton: legacy product manuals,
generated documentation, citation metadata, and distribution packaging have been
removed.

Start every work session with [SESSION_START.md](SESSION_START.md).

## Foundation retained

- Document extraction, metadata, lexical indexing, and search engine source.
- Qt application and Python binding source needed for the rebuild.
- Component licenses, copyright notices, and provenance required by the inherited GPL
  code.
- Experimental local semantic search and the new hash-chained event ledger.
